# Kaiser 申请方向：已完成的 NHANES 项目

本项目是独立公开数据作品，不代表在 Kaiser 工作或临床研究经历。
使用 CDC 2017–2018 四张官方表，完成来源和哈希记录、主键验证、一对一合并、
逐变量缺失编码、互斥样本排除、复杂抽样域分析、敏感性分析和自动报告。

实际完整病例 4,940 人。调整年龄和源数据性别类别后，每 5 kg/m² 更高 BMI
对应 HbA1c 高 0.125 个百分点（95% 区间 0.103–0.146）。该结果只能描述关联。
未自报糖尿病域的系数为 0.075（0.061–0.090），不是“无病人群”的确认。

运行方法见英文 README。运行后在浏览器打开 reports/report.html：支持年龄域、
加权/未加权口径和敏感性模型切换，可下载真实汇总表。brief.pdf 是两页英文简报，
适合求职展示。docs/resume_bullets.md 仅使用实际完成的可核查表述。

值得面试解释的实际问题：pandas 把 XPT 中 550 个零权重读成极小正数；R 解码
和跨语言对账揭示并修复了这个样本设计错误。没有通过删除真实极值来美化分布。

## ML 补充

新增 HbA1c 连续值预测：按 PSU 分组的五折验证，比较均值、岭回归与梯度提升。加 BMI 的岭回归加权 MAE 为 0.4867，均值基线为 0.5460；这次复杂模型没有胜过线性模型。不能把横截面预测写成未来糖尿病预测。

打开 `reports/ml_report.html` 查看模型比较、变量重要性、分组误差及校准图（CMS）；`reports/ml_brief.pdf` 是一页英文摘要。仍使用原来的一键命令运行全部分析和测试。
